# Agent Instructions

## Project

- This is a Next.js application using the App Router.
- Application routes and page components belong in `app/`.
- Reusable UI components belong in `app/components/`.
- Use TypeScript and follow the existing project style.

## Development

- Keep changes focused on the requested task.
- Reuse existing components and patterns before adding new ones.
- Do not edit generated directories such as `.next/` or dependency directories such as `node_modules/`.
- Do not add secrets, credentials, or environment-specific values to source control.

## Validation

- Run `npm run lint` after code changes.
- Run `npm run build` when changes affect routing, configuration, or production behavior.
- Check `git diff` and `git status` before committing.

## Git

- Use a descriptive branch for each piece of work.
- Make small, focused commits with clear messages.
